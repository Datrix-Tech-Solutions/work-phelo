## Standard Notes

- Reinsurance publishes business facts only. Accounting owns GL selection,
  posting direction, fiscal-period validation, subledger validation, balanced
  journal creation and retries.
- Issued notes, payments and reversals are durable source records. Draft notes,
  preview documents and UI calculations are not accounting recognition
  boundaries.
- `CURRENT_COMMIT` should be replaced with the final implementation commit only
  if that can be done without rewriting published history. Otherwise the commit
  SHA should be reported in the release summary.
