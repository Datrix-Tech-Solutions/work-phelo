## Standard Notes

- Reinsurance publishes business facts only. Accounting owns GL selection,
  posting direction, fiscal-period validation, subledger validation, balanced
  journal creation and retries.
- Issued notes, payments and reversals are durable source records. Draft notes,
  preview documents and UI calculations are not accounting recognition
  boundaries.
- `CURRENT_COMMIT` should be replaced with the final implementation commit only
  if that can be done without rewriting published history. Otherwise the commit
  SHA should be reported in the release summary.
- Reinsurer disbursement reversal remains planned. The governing audit is
  [Reinsurance Settlement Architecture Audit v1](./reinsurance-settlement-architecture-audit-v1.md)
  and the required Finance decisions are tracked in
  [Reinsurance Settlement Policy Decision Register v1](./reinsurance-settlement-policy-decision-register-v1.md).
- Claims accounting activation is governed by
  [Reinsurance Claims Accounting Architecture Audit v1](./reinsurance-claims-accounting-architecture-audit-v1.md)
  and
  [Reinsurance Claims Accounting Policy Decision Register v1](./reinsurance-claims-accounting-policy-decision-register-v1.md).
